# v1.1.0 — 自动探索图形界面版

这是加入动物、植物、矿物扫描之前的版本。

- 自动打开普通银河地图、选择可达恒星并进行货船跃迁。
- 跃迁加载完成后扫描整个恒星系，登记行星发现。
- 图形界面显示运行阶段、跃迁和扫描次数、上传记录数，可设置次数或时间上限。
- F1 启动 / 暂停 / 继续；F2 开关自动上传（默认关闭）；F3 停止。
- 不发送键盘或鼠标输入，不依赖货船房间布局。

**不包含动物、植物、矿物自动扫描，也不包含该功能的实验性原生生成调用。**

## 下载与运行

下载附件 `NoMansSkyScanner-v1.1.0-NMS170671.zip`，完整解压后运行 `NoMansSkyScanner.exe`。便携包包含 Python 和锁定版本的运行依赖，无需另外安装 Python。EXE 需要与 `runtime`、`native`、`nms_scanner` 目录放在一起。

仅适用于 Windows 11 x64、Steam 游戏内部版本 **170671**。游戏 EXE 的 SHA-256 必须为 `ea7e5a29bbf931f96ae8dda81553353aab3431dc38e4ed7dfb66bdce100770e3`；其他版本会被启动检查拒绝。

先备份存档并使用测试存档，角色站在自己的货船内。若此前运行过扫描器，先完全退出并重启游戏，再使用此版本。停止会阻止后续动作，无法撤销已开始的跃迁；退出游戏才能卸载注入的运行时。

自动上传开启后会处理存档中全部符合条件的待上传发现，包括历史发现。后台完整循环及窗口最小化尚未单独验收。

## 验证

核心跃迁、整系扫描、F1 暂停 / 继续、F2 上传和 F3 停止已有游戏测试记录。图形界面命令通道有非游戏测试，界面按钮尚无单独的完整游戏验收记录。本次发布经过 68 项非游戏测试、Ruff、编译检查和发行包源码一致性检查；没有重新连接游戏。

ZIP 由 GitHub Actions 从本 Release 对应源码构建，使用 Python 3.12.10 x64 和 `requirements.lock.txt` 的精确依赖版本。附件 `.zip.sha256` 可用于完整性校验。
