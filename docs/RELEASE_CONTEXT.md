# NoMansSkyScanner 项目上下文

当前源码：1.1.2-rc1，适配目标 Steam Cosmos 7.0 内部版本 178763 / build 25208023。

项目从前台自动化验证发展为 Windows 原生函数调用工具。当前经用户授权的范围包括货船常规随机跃迁、加载后整系行星扫描、图形界面、可选上传、光谱/类别/地图标签/主导种族多选筛选与后台运行尝试。

F1 开始/暂停/继续，F2 切换自动上传（默认关闭），F3 停止。筛选默认关闭。类别与种族分别多选，含无人类别时允许保留其他种族，并提供无主导种族选项。保留每轮与最长运行时间上限。

不包含动植物矿物扫描、类地星球预设、存档修改、银河切换或银河中心路线。代码不发送键盘鼠标输入，不依赖货船房间布局。

本版是待实测的适配测试版。16 个入口与关键布局已做本机离线核查，102 项非游戏测试通过。旧 170671 的日志不能作为 178763 验收。扫描前新增货船内部状态与连续世界更新稳定检查，但尚未证明解决碰撞恢复或穿出货船问题。

维护时先核对 native/profile.json 的精确 SHA-256，再核对完整调用约定及对象布局；不要只更改版本号或地址。所有实际测试使用已备份的测试存档。一次跃迁扫描通过后再验收两轮循环及其他选项。Ruff、unittest、compileall 和发行包核查须通过。

研究依据：research/COSMOS_COMPATIBILITY.md。发行说明：releases/v1.1.2-rc1.md。
